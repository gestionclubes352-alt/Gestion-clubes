┌─ OPTIMIZACIONES ESPECIALES ───────────────────────────────────────────────┐
│                                                                             │
│  ⚠️ PORTÁTIL 13" (1280×800):                                               │
│     • Altura limitada = scroll vertical necesario                          │
│     • Media queries por altura: h-sm:, h-md:, h-lg:                       │
│     • Modales max-h-[80dvh] para no desbordarse                           │
│     • Padding vertical reducido en h-sm                                    │
│     • Sidebar mantiene 280px de ancho                                      │
│                                                                             │
│  🖥️ MONITORES 27"+ (2560×1440):                                            │
│     • Padding muy generoso (px-12, py-10, etc.)                          │
│     • Fuentes escaladas (text-lg, text-xl, text-2xl)                      │
│     • Grid de 4-6 columnas                                                 │
│     • Sidebar ligeramente más ancho (300px, 320px)                        │
│     • Scrollbar más visible (10-12px)                                      │
│                                                                             │
│  📱 LANDSCAPE (móvil horizontal):                                           │
│     • Auto-colapso de sidebar en pequeña altura                            │
│     • Reducción de padding vertical                                        │
│     • Gap reducido entre elementos                                         │
│                                                                             │
│  🎯 TYPOGRAPHY FLUIDA:                                                      │
│     • Variables CSS con clamp(): crece suavemente                          │
│     • Sin saltos abruptos en breakpoints                                   │
│     • Responsive sin media queries adicionales                             │
│                                                                             │
